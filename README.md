# movie-savings-java
Java console application demonstrating object-oriented programming, input validation, ArrayLists, and custom exception handling.

## Technologies Used

-   Java
-   Object-Oriented Programming
-   Interfaces
-   ArrayLists
-   Custom Exception Handling
-   Input Validation
-   Conditional Logic and Loops

## Features

-   Collects user information through console input
-   Validates user age
-   Categorizes users based on movie-rating eligibility
-   Stores users in categorized collections
-   Displays savings information
-   Handles invalid age entries with a custom exception

## What I Practiced

-   Classes and objects
-   Interfaces
-   ArrayLists
-   Conditional statements
-   Loops
-   Exception handling
-   Input validation
-   Organizing application output

## How to Run

1.  Open the Java files in a Java IDE such as Apache NetBeans, JGrasp,
    or VS Code with Java support.
2.  Compile the project.
3.  Run `MovieSavingsDriver.java`.
